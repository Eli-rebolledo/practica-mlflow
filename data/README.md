# data/

Aquí van los datos del proyecto. El archivo por defecto es `final_student_dataset.csv` (`DATA_PATH` en `.env.example`).

`final_student_dataset.csv` pesa ~56 MB, así que NO se sube a Git (está en `.gitignore`). Cada persona lo copia a esta carpeta en local.
`data_dictionary.csv` es pequeño y sí puede vivir en Git.
